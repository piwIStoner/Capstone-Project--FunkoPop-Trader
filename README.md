For my Project FunkoPop Trader I included the help of AI to get some of my application functioning. AI from chatgpt and google AI were used to bring some of my project together. For example,
the login form and create new user form AI was used to store a user's information into the database. It was also used allowing a user to upload a photo for their account and add, also save a
bio to the user's page. When users add funko pops worth trading and those that are a part of their collection they are able to show up on the user account page and to view the whole collection.
AI was also used to incorporate the maps into my application, where the user is able to see who is in the vicinity to trade.
